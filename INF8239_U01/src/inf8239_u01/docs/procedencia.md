# Ficha de Procedencia y Licencia de los Datasets

## Adult Income
- **Fuente:** UCI Machine Learning Repository (https://archive.ics.uci.edu/ml/datasets/adult)
- **Descripción:** Datos del censo de EE.UU. utilizados para predecir si una persona gana más de 50K al año.
- **Licencia:** Uso académico y de investigación permitido.
- **Notas:** Dataset ampliamente utilizado en estudios de clasificación y fairness.

## Student Dropout
- **Fuente:** UCI Machine Learning Repository (https://archive.ics.uci.edu/ml/datasets/student+performance)  
  *(dependiendo de la versión, también disponible en repositorios educativos)*
- **Descripción:** Información académica y demográfica de estudiantes, utilizada para predecir abandono, graduación o permanencia.
- **Licencia:** Uso académico y de investigación permitido.
- **Notas:** Dataset con clases desbalanceadas, especialmente la categoría “Enrolled”.
